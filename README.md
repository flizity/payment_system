# 💳 Payment system v2 

## 🚀 Улучшения в версии 2.0

### 🔄 Новые возможности
- **Межпользовательские переводы**  
  Безопасные транзакции между счетами с проверкой баланса

- **Очередь транзакций**  
  Асинхронная обработка операций с системой статусов:
  - Ожидание → Успех/Ошибка

- **Полная история операций**  
  Фиксация времени, суммы и статуса каждой транзакции

### ⚙️ Технические особенности
- Автоматический откат при ошибках
- Детализированный мониторинг статусов
- Поддержка высокоточных сумм (float64)

## 📈 Пример работы
[15:30:45] 14773 → 23432: $100.50 (успешно)
[15:30:45] 23432 → 14773: $5000.00 (успешно)

Баланс Alex: 6,899.50
Баланс Max: 9,900.50
